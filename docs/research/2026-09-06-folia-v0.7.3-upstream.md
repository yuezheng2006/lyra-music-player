## 10. Visualizer：lazy render + 模式 id 脱离 registry

## 使用注意 / 移植冲突

- 全局 Cmd+K 与 Lyra 现有 **Cmd+S** 并存即可；Folia 裸 S 会打到网格筛选，必须配交互开关，不要默认跟。
- Folia 队列 **Cmd+P** 与 Lyra **右侧面板 Cmd+P** 冲突，保持 Lyra。
- staff 策略是 display 层决策，不要写进歌词 parse/cache。
- 启动自动续播必须在 `restorePlaybackSourceForSong` **之前** arm `shouldAutoPlayRef`，否则桥接 effect 会错过。
- 分词覆盖保存后要立刻 invalidate 布局（`f4bc28f0`），不要等切歌。
- 开屏：保留 Lyra min-dwell，不要抄 Folia「useEffect 即 hide」。
